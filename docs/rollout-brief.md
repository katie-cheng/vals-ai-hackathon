## 2. Harbor task formats that exist

### 2a. `harbor-tasks/v1-deb-html/` — v1 draft (merged, PR #5; "probably won't be used")
- 26 tasks `deb/web-01 … web-26`, generated by `generate.py` from `prompts.md` (= `data/website-prompts-db/` system prompt + 26 briefs, verbatim).
- `instruction.md` = Aidan's system prompt + the brief + one delivery line: "Save the complete HTML document to `/app/index.html`."
- `task.toml` schema 1.4: agent timeout 1800 s, env 2 CPU / 4 GB / network public, verifier 600 s, `environment_mode = "separate"`, `artifacts = ["/app/index.html"]`.
- `environment/Dockerfile`: `ubuntu:24.04` + curl/git, WORKDIR `/app`. Agent writes one file.
- `tests/`: Playwright-python image; `render.py` opens the page at 1440 px and 390 px, saves `verifier/render/{desktop,mobile}.png`, `*.dom.html`, `render_log.json`; `reward.json` = 1 if it loads at both sizes with real text, else 0. **No slop checks, no brief-fulfillment.**
- Smoke-tested on local Docker with Harbor `oracle` (1) and `nop` (0). No model has run.
- Why it's "v1": single-file HTML (contradicts the AGENTS.md decision that tasks are multi-file Vite/React like Design Arena) and render-only grading.

### 2b. `tasks/zee-beauty-salon/` — v2 format (merged, PR #9, from Ali's session) — the intended architecture
- `instruction.md` = delivery rules (work in `/app`, Vite + React + TS, `npm run build` → `/app/dist`, client-only, no console errors, images must load) + the Design Arena brief verbatim (ZEE Beauty Saloon, tournament 0c087e06…, sites S03 gpt-6-astra-max / S04 kimi-k3.1-pro).
- `task.toml`: `slopbench/zee-beauty-salon` 0.1.0, agent 3600 s, verifier 900 s, env 4 CPU / 8 GB / 10 GB, **shared** verifier mode (verifier runs in the agent's container).
- `environment/`: `mcr.microsoft.com/playwright:v1.64.1-noble` + Playwright npm in `/opt/verifier`, template Vite app in `/app` with `npm ci` done.
- `solution/`: golden reference site + `solve.sh` (oracle).
- `tests/`: `test.sh` rebuilds `/app` (build failure → reward 0), then `grade.mjs` (generic: serves dist, renders 390/768/1280/1440/1920 + a 1920→360 resize sweep, scores, saves screenshots + HTML), `probe.mjs` (generic in-page facts + slop-pattern counts), `task.mjs` (task-specific requirements checklist + interactions).
- Reward: `gate × (requirements + slop)/2`. `slop = 1/(1 + points/15)`, points from SlopLabel-derived patterns (eyebrows, heading accent spans, `·` separators, pills, oversized rounding, numbered markers, em dashes, emoji/dingbat icons, gradient text, pulsing dots, tiny text, duplicate CTAs, broken/wrapping controls), each with a free allowance; brief-requested styles are exempt.
- To add a task: copy `grade.mjs`/`probe.mjs` unchanged, write a new `task.mjs` (see `tasks/README.md`).

### 2c. Golden references `references/S13` (Suds Squad, Katie signed off) and `references/S30` (Kora, PRs #10–#13)

## 3. Run plan (proposed 2026-11-14 23:47; not confirmed)

1. **Harness**: one harness for all models so the comparison measures the model, not the agent → Harbor `terminus-2` (LiteLLM, any provider, `reasoning_effort=high`). Alternative: vendor-native (Claude Code / Codex / muse-code / kimi-cli) — closer to how people use them, but mixes harnesses. Decision pending.
2. **Tasks**: today only v1 (26 tasks) is runnable end-to-end for arbitrary briefs; v2 has exactly one task (zee). Running v1 gives us each model's `index.html` + screenshots per brief as artifacts to label in SlopLabel and regrade later; the reward itself is only "renders".
3. **Order**: pilot 4 keyed models × 5 tasks × 1 attempt locally (~1 h, ~$5–15) → full 26 × 4 → open models when a key lands → repeat on v2 tasks as they're built. Quality first: label the pilot output before scaling.
4. **Seeds**: `-k 3` attempts per task once the harness is stable, to measure variance.
5. **Outputs**: Harbor job dir (`jobs/<name>/<trial>/` with trajectory, `verifier/`, artifacts) committed to the repo on a branch (`runs/`), screenshots imported into SlopLabel as new sites, real render-pass rate (only) replaces placeholders on the DEB site, labeled as such.
