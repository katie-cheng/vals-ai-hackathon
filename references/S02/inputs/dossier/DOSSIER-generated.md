Variables & Declarations (ES6+)

Modern JavaScript eliminates "var" in favor of block-scoped declarations.

Syntax Reference:
Copy Snippet
// const: preferred for all variables that will not be reassigned
const course = "IT Beginner";
const maxScore = 100;

// let: used only when variable must be reassigned
let completedLessons = 0;
completedLessons += 1;

// Primitive Data Types
const name = "Alex";        // String
const streak = 7;           // Number
const isActive = true;      // Boolean
const empty = null;         // Null (explicit empty value)
let notSet;                 // Undefined
Best Practices & Tips:
Default to const; change to let only when reassignment is needed.
Never use var in modern codebases.
Strict Equality & Conditionals

Always use triple equals (===) to prevent unexpected type coercion bugs.

Syntax Reference:
Copy Snippet
// Strict equality checks value AND type
5 === 5;     // true
5 === "5";   // false (number vs string)
5 == "5";    // true (type coercion - avoid!)

// Logical operators
if (score >= 90 && attendance >= 80) {
  console.log("Certificate with Distinction");
} else if (score >= 70) {
  console.log("Passed Course");
} else {
  console.log("Review Lessons");
}
Best Practices & Tips:
Use ternary operator (condition ? exprIfTrue : exprIfFalse) for inline assignments.
Essential Array Methods

Functional array methods for transforming, filtering, and aggregating data.

Syntax Reference:
Copy Snippet
const fruits = ["Apple", "Banana", "Cherry"];

fruits.push("Mango");   // Append to end
fruits.pop();           // Remove last item

// .map() - transform each item into a new array
const upper = fruits.map(f => f.toUpperCase());

// .filter() - return items matching condition
const bFruits = fruits.filter(f => f.startsWith("B"));

// .reduce() - calculate single aggregated value
const numbers = [10, 20, 30];
const sum = numbers.reduce((acc, curr) => acc + curr, 0);
