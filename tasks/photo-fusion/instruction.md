You are working in `/app`, a Vite + React + TypeScript project with its dependencies already installed.
Build the website described in the brief below inside this project.

- `npm run build` must succeed and write a static site to `/app/dist`. The site is served from `/app/dist` as static files at `/` and opened in Chromium at desktop, tablet and phone sizes.

Create a modern, professional and fully responsive website called PHOTO FUSION – Image Merger. The website allows users to combine multiple photos into one beautiful image easily. The main features include uploading multiple images from phone or PC, drag and drop images, merging 2, 3, 4 or more photos, choosing horizontal or vertical layout, creating photo collages and grids, adjusting image size, spacing and borders, adding backgrounds and custom colors, previewing the final result instantly, downloading the merged image in high quality (PNG or JPG), removing or rearranging uploaded photos, and a simple and attractive user interface. The design should feature premium modern UI with white and dark blue colors and purple gradients. Incorporate beautiful animations and smooth transitions, a large upload button, and an easy-to-use editing workspace, ensuring mobile, tablet, and desktop compatibility. Important: All image merging and editing must work directly inside the website, not just be a visual demonstration. No login is required. Do not include products or an online store.
